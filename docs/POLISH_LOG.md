# 五轮优化记录

基础版：13件可交互模型、分类、旋转/缩放、线框与GLB/STL导出；独立仓库和Pages发布，不修改原游戏。

## 第1轮：材质与藏品预览

- 调整曝光与环境光，增加金属纹理和颜色层次。
- 为全部13件模型生成真实WebGL预览，替换列表符号。
- 检查真实渲染、预览数量、五种宽度和模型下载。

## 第2轮：观察与分享

- 增加前后藏品导航、正面/背面/侧面视角、缩放与全屏。
- 支持键盘方向键、加减键与Home复位。
- 深链接直接定位单件模型，复制失败时提供可选中的链接。
- 验证视角工具、键盘操作、切换和基础浏览器回归。

## 第3轮：实体结构与分层

- 针脚沿每种芯片边缘布置，减少脱离主体的视觉问题。
- 八块芯片补充背板、电路走线与编号触点。
- 增加分层展开，下载保持原始装配状态。
- 验证全部13件网格、STL、展开复原和浏览器操作，更新模型预览。

## 第4轮：性能与设备兼容

- 静止时不重复绘制，视区离屏或标签页隐藏时暂停渲染；移动端限制渲染分辨率。
- 仅打包实际使用的Three.js扩展，保留本地加载。
- WebGL不可用或连接丢失时展示实拍预览，保留浏览与下载；提供重新加载入口。
- 系统减少动画设置下禁用自动旋转，并改善小文字对比。
- 验证真实WebGL、无WebGL降级、减少动画与手机布局。
